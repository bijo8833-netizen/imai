# imai

## 경정청구 항목·환급액 산출기 (`app/`)

경정청구(更正請求)에 필요한 항목을 입력하면, 해당 가능한 경정청구 항목과 예상 환급 세액을 자동으로 산출하는 웹 도구입니다.

### 사용 방법

```bash
cd app
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

빌드 과정 없이 정적 파일(`index.html`, `style.css`, `app.js`, `rules.js`, `govSupport.js`)로 동작합니다.

### 탭 1·2 — 경정청구 항목·환급액 산출기

- **법인세**: 감가상각비 과소계상, 대손금 누락, 이월결손금 공제 누락, 세액공제 누락, 기업업무추진비 한도 재계산, 퇴직급여충당금 누락, 재고자산평가손실, 외화환산손실, 가지급금 인정이자, 기부금 한도초과 이월공제 등 10개 항목
- **부가가치세**: 매입세금계산서 누락, 신용카드매출전표 매입세액, 의제매입세액공제, 대손세액공제, 불공제매입세액 환원, 영세율 재계산 등 6개 항목

법정신고기한을 입력하면 국세기본법 제45조의2에 따른 경정청구 기한(5년) 이내 여부도 함께 판정합니다.

경정청구는 신고일로부터 5년 이내 여러 사업연도(신고기간)에 걸쳐 확인해야 하므로, 각 탭 하단의 **"여러 연도 한번에 계산(엑셀 업로드)"**에서 "엑셀 템플릿 다운로드"로 양식을 받아 최근 5개년 자료를 한 번에 채운 뒤 업로드하면 연도별 환급 예상액과 청구기한(5년) 경과 여부를 표로 한번에 확인할 수 있습니다.

### 탭 3 — 정부지원·세액감면 매칭 리포트

회사 프로필(기업규모, 업종, 소재지, 설립일, 투자·R&D·인건비 등)을 입력하면 아래 두 축으로 나눠 매칭 결과를 보여줍니다.

- **세액공제·감면(확정형, 국세청·기획재정부)**: 창업중소기업 세액감면, 중소기업 특별세액감면, 통합투자세액공제, 연구인력개발비 세액공제, 통합고용세액공제, 성과공유 중소기업 경영성과급 세액공제 — 요건 충족 시 법에 따라 확정 적용되는 금액
- **정부지원사업·보조금(공모/심사형, 고용노동부·중소벤처기업부)**: 청년일자리도약장려금, 고용창출장려금, 두루누리 사회보험료 지원, 예비/초기/창업도약 패키지, 중소기업 혁신바우처, 스마트공장 구축지원 — 예산 한도 내 공모·심사로 선정되므로 표시 금액은 신청 가능 한도(참고치)이며 확정 지원액이 아님을 리포트에 명시

매년 4,000개 이상 공고되는 정부지원사업 중 업종을 가리지 않고 폭넓게 적용되는 대표 제도만 선별해 수록했으며(전수 조사 아님), 전체 최신 목록은 기업마당(bizinfo.go.kr)·고용24(work24.go.kr)·K-Startup(k-startup.go.kr)에서 확인해야 합니다.

### 구조

- `app/rules.js`: 경정청구 항목 정의, 법인세 누진세율 계산, 경정청구 기한 계산
- `app/govSupport.js`: 정부지원·세액감면 매칭용 회사 프로필 필드, 제도별 자격요건(`eligible`)·금액 추정(`estimate`) 규칙 (신규 제도 추가 시 이 파일의 `PROGRAMS` 배열만 확장하면 됨)
- `app/app.js`: 탭 전환, 폼 렌더링, 사용자 입력 수집, 결과·리포트 출력, 엑셀 템플릿 다운로드/업로드 기반 다년도 일괄 계산
- `app/index.html`, `app/style.css`: UI
- `app/vendor/xlsx.full.min.js`: 엑셀 읽기·쓰기용 SheetJS(MIT/Apache-2.0) 라이브러리(오프라인 동작을 위해 로컬에 포함)

## 전자책(PDF) 가이드북 생성기 (`ebook/`)

`app/`의 내용을 초등학생도 이해할 수 있도록 쉽게 풀어 쓴 전자책을 PDF로 만드는 프로그램입니다. 회사명 배지가 포함된 표지, 항목별 카드(쉬운 설명·준비서류·입력 방법), 준비서류 체크리스트를 담은 A4 PDF를 생성합니다.

```bash
cd ebook
python3 build.py   # ebook.html 생성
node render.js      # PDF 변환(guidebook.pdf) — Playwright + Chromium 필요
```

자세한 사용법·커스터마이징(회사명, 내용, 디자인)은 `ebook/README.md` 참고.

## 소스코드 PDF 생성기 (`codebook/`)

`app/` 폴더의 계산 앱 소스코드 전체(index.html, style.css, app.js, rules.js, govSupport.js)를 구문 강조(syntax highlight)·줄번호가 있는 인쇄용 PDF로 뽑는 프로그램입니다.

```bash
cd codebook
pip install pygments
python3 build.py   # source.html 생성
node render.js      # PDF 변환(source-code.pdf) — Playwright + Chromium 필요
```

자세한 사용법은 `codebook/README.md` 참고.

### 유의사항

- 모든 계산 결과는 입력값 기준의 **참고용 추정치**입니다. 법인세 경정청구는 국세만 계산하며(지방소득세는 별도 경정청구 대상), 정부지원사업 매칭 결과 중 공모형 항목은 확정 지원액이 아닙니다.
- 실제 경정청구서 제출·정부지원사업 신청 전 반드시 세무 전문가(세무사) 및 소관 부처·기관의 최신 공고 확인이 필요합니다.
- 감면율·지원단가는 매년 개정되므로 `govSupport.js`의 수치는 2026년 기준 근사치이며 주기적인 업데이트가 필요합니다.
- 종합소득세 등 다른 세목/제도는 각각 `TAX_TYPES`, `PROGRAMS` 구조를 따라 추후 확장 가능하도록 설계되어 있습니다.
