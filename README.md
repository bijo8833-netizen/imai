# imai

## 경정청구 항목·환급액 산출기 (`app/`)

경정청구(更正請求)에 필요한 항목을 입력하면, 해당 가능한 경정청구 항목과 예상 환급 세액을 자동으로 산출하는 웹 도구입니다.

### 사용 방법

```bash
cd app
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속
```

빌드 과정 없이 정적 파일(`index.html`, `style.css`, `app.js`, `rules.js`)로 동작합니다.

### 현재 지원 세목

- **법인세**: 감가상각비 과소계상, 대손금 누락, 이월결손금 공제 누락, 세액공제 누락, 기업업무추진비 한도 재계산, 퇴직급여충당금 누락, 재고자산평가손실, 외화환산손실, 가지급금 인정이자, 기부금 한도초과 이월공제 등 10개 항목
- **부가가치세**: 매입세금계산서 누락, 신용카드매출전표 매입세액, 의제매입세액공제, 대손세액공제, 불공제매입세액 환원, 영세율 재계산 등 6개 항목

법정신고기한을 입력하면 국세기본법 제45조의2에 따른 경정청구 기한(5년) 이내 여부도 함께 판정합니다.

### 구조

- `app/rules.js`: 세목별 경정청구 항목 정의, 법인세 누진세율 계산, 경정청구 기한 계산 등 핵심 규칙 (신규 세목 추가 시 이 파일만 확장하면 됨)
- `app/app.js`: 폼 렌더링, 사용자 입력 수집, 결과 출력
- `app/index.html`, `app/style.css`: UI

### 유의사항

- 계산 결과는 입력값 기준의 **참고용 추정치**이며, 법인세는 국세만 계산합니다(지방소득세는 별도 경정청구 대상).
- 실제 경정청구서 제출 전 반드시 세무 전문가(세무사)의 검토가 필요합니다.
- 종합소득세 등 다른 세목은 `TAX_TYPES` 구조를 따라 추후 확장 가능하도록 설계되어 있습니다.
